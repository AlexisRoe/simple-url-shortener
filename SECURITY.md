# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub:
[Report a vulnerability](https://github.com/AlexisRoe/simple-url-shortener/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit you tested. I aim to
acknowledge a report within 7 days and to tell you how I plan to handle it within 30 days.

## Scope

The API, redirect handling, authentication and the Caddy and container configuration in this repository.

## Supported versions

Only the latest release is supported.
